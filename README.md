**Летняя учебная практика выполненна студентами группы 4342:** Купчинский Ян, Садыков Семён, Тиссен Михаил

По UI на момент 23:07 06.07.2026:
 1. Верхняя часть: Область отображения графа (canvas), где 
   пользователь может создавать вершины и рёбра.

2. Правая часть: Панель управления с кнопками:
   - Шаг вперёд ->
   - Шаг назад <-
   - Старт
   - Стоп

3. Нижняя часть: Окно результатов с таблицей, содержащей:
   - Инфу по графу и вершинам

Взаиомдействие с приложением:
- Стартовая вершина выбирается двойным кликом мыши - у нее будет меняться цвет
- Повторный двойной клик снимает выделение
- Без выбранной стартовой вершины алгоритм не запускается
